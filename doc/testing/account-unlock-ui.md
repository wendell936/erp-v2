# 管理员解除临时锁定页面验收

日期：2026-10-11。任务：P0-17.b，依据需求第 11 章。后端接口、实际 Redis、权限拒绝和审计已有独立验收，见执行记录 E024；本地 Docker 安装完成后，本轮重新运行后端集成测试并补齐真实页面联调，见 E028。

## 页面与参考

实施前在本地内置浏览器查看领星用户管理页：紧凑筛选、状态与角色筛选、列表右侧行内操作及分页；只有超级管理员一条数据，未观察到解除临时锁定入口。采用其行内操作方式，具体解锁规则来自本项目需求。

用户列表增加“解除锁定”，使用独立 `system:user:unlock` 权限，调用 `PUT /system/user/unlock/{userId}`。管理员目标也可操作，与后端契约一致。列表没有锁定实时状态字段，因此不显示未经查询的锁定标签；入口可清除失败计数及临时锁定。

确认框显示目标用户名及影响：只清除密码失败次数，不修改密码，停用账号保持停用。确认框和请求期间禁用当前行按钮，取消和失败恢复按钮，失败不刷新列表或丢失筛选。沿用统一请求错误提示。

## 本次实际验证

使用实际 Vue 页面、权限指令及请求封装，配合仅监听本机的合成 API。测试工具放 `.local/qa/`，日志放 `.local/logs/P0-17/`，均不入库；没有使用真实账号密码。

| 取消 | 按钮恢复，API 日志没有取消产生的 PUT |

## 真实前后端联合验收

本轮使用实际构建 jar、Vue 页面、MySQL 8.4.11 与 Redis 7.4，均仅监听本机；随机创建独立容器与空库，不连接业务库。沿用基线合成账号，清空样例联系方式，临时只读角色仅有用户列表/查询权限。仅该临时库关闭验证码；验证码单次消费、错误及并发边界仍由本轮通过的 LoginFlowIT 覆盖。

| 场景 | 实际结果 |
|---|---|
| 锁定与取消 | 临时 Redis 布置 `pwd_err_cnt:ry=5` 后正确密码被拒；管理员取消解锁，计数仍为 5，解锁审计为 0 |
| 确认解锁 | 实际页面出现成功提示，Redis 键不存在；原密码再次登录成功 |
| 审计 | `sys_oper_log` 记录 admin 调用 `/system/user/unlock/2`，status=0；启用和停用场景各一条 |
| 真实只读账号 | 同一真实后端返回两条用户记录，解锁按钮数为 0 |
| 停用且锁定 | 独立布置 user_id=2 停用且计数5；页面解锁提示仍为停用，Redis键清除，数据库 status=1；原密码登录返回“用户已封禁，请联系管理员” |
