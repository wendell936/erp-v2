# 首个业务闭环验收基准

本样例为可重复的合成测试场景，不是正式商品编码、正式报价或已执行的验收结果。真实首组商品资料到齐后补充实际验收，保留此场景用于回归。

## 固定输入

- 测试套装 KIT-TEST 配方 v1：每套组件 A 两件、组件 B 一件；提需十套。所有数量单位为件，相关金额均为 CNY。
- 供应商甲采购 A 二十件，单价五元；供应商乙采购 B 十件，单价八元。拆成两张采购单和两票国内运单。
- A 一票运费二十元，分两次各合格收货十件；B 一票运费十元，一次合格收货十件。无不良、损耗或其他费用。费用均在最终验收前确认。
- 加工十套，每套加工费两元，已含包材，不另计包材；分两次各完工五套。
- 实际发往 FBA 十套，Amazon 接收十套。为隔离本场景计算，头程明确填写已确认零费用，不以缺失费用代替零。
- 销售三套，每套收入四十元、平台费用五元；无广告、经营费用、退款或其他费用。本场景测试库明确这些费用确实为零。

## 预期结果

| 环节 | 预期 |
|---|---|
| 净需求与采购 | A 二十件、B 十件，按两个供应商拆单；重复生成不增加采购 |
| 首次 A 收货 | A 入库十件；B 未入库时不可加工成品；运单与采购进度保留 |
| 收货完成 | A 二十件，最终单位成本六元；B 十件，单位成本九元；合计库存成本二百一十元 |
| 加工完成 | 组件余额零，成品十套；每套成本二十三元，总成本二百三十元；第一次完工后成品五套且保留剩余进度 |
| 发货与接收 | 国内成品减少十套，阶段间转移不丢失成本、不重复计量；FBA 接收十套，总成本二百三十元 |
| 三套销售 | 收入一百二十元、销售成本六十九元、平台费用十五元，直接利润三十六元；FBA 剩余七套、成本一百六十一元 |
| 可追溯性 | 销售可追至成品批次、投料批次、采购行、运单、配方及费用来源 |

分批收货过程中运费暂估及后续分摊按实现规则验证，最终合计必须为三十元；禁止重复分摊。

## 必要变体

- 重复确认采购、收货、完工、平台订单同步，数量和金额均不重复变化。
- 超额收货、组件不足投料、超额完工、超额发货被拒绝；并发抢占不能导致重复分配或负库存。
- 多批次存在不同价格时，验证实际 FIFO 投料与成本，不以均价替代。
- 使用 USD 的独立场景确认汇率快照，随后修改汇率不改变已确认成本；缺汇率时进入待处理状态。
- 修改配方或图片后，历史单据仍引用原版本；被引用商品不能直接删除。
- 原SKU已有库存后新增变体，原编号、库存、业务和历史不变，新变体使用追加后缀的独立身份；不因父子展示重复汇总库存或自动转移数量。
- 不同成品组合共享同一组件SKU，按各自版本配方和实际占用办理，不能向两个组合重复承诺组件；组合Seller SKU展开组件不额外扣减组件销售成本。
- 商品参考头程取不晚于测算日的最近已维护汇率并显示日期；仅有未来汇率时提示待补。实际费用指定日缺汇率仍待补，不能沿用参考取值规则；改变参考运价、包装或汇率不直接更改已确认库存及销售成本。
- 后补运费或暂估转实际时，已售成本与剩余库存分别调整且总额守恒。
- 可售实物退货恢复原销售成本；退款与实物退货独立处理，不重复计损。
- 无权限访问、事务中途失败和同步中断验证业务无部分脏写，恢复后不重复产生结果。
- 应付款及部分支付与费用发生分离，账户转账不影响利润；未到账收入不增加可用现金。
- 数据缺失、外部失败和无记录在界面明确区分，不显示为已确认零成本或净利润。
