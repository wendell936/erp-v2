# 日期汇率页面验收

任务：P1-18.a、P1-19。2026-10-11在Windows本地完成；业务口径见[接口与规则](../development/dated-exchange-rates.md)，任务及过程见[台账](../development/task-board.md)和[执行记录](../development/execution-journal.md)。

## 环境与范围

实际启动本次构建的Spring Boot jar、Vue/Vite页面、随机隔离MySQL8.4及Redis7.4，仅绑定本地回环地址。使用合成操作和只读账号、合成日期及金额，没有连接正式库、真实供应商或店铺。UI夹具直接按顺序执行7份迁移SQL，启动时Flyway关闭；真实Flyway初始化、既有版本升级和重复执行由独立的完整集成回归验证，不能以页面夹具代替。

通过浏览器实际登录、导航“基础资料 → 日期汇率”、操作表单和读取反馈；故障注入及并发更新仅作用于本次可丢弃数据库。管理员权限和三角色菜单也经真实HTTP集成测试验证。参考领星只读观察见[交互记录](../development/lingxing-interaction-reference.md)。

## 实际结果

| 场景 | 操作及可核对结果 |
|---|---|
| 空表与校验 | 空表显示暂无日期汇率；新增空日期/金额拒绝，修改缺原因拒绝，已存在记录日期禁用 |
| 新增与舍入 | 页面新增2026-10-11汇率7.50000000、版本0；预览0.01 USD得到0.08 CNY，显示日期、8位汇率及版本 |
| 精确日期缺失 | 改为2026-10-12提示缺该日汇率，原结果清除，不沿用10-11或显示0；CNY -1.23无需汇率仍为-1.23 |
| 修改与历史 | 修改为7.25000000、版本1，保存人员及原因；历史版本0仍为7.50000000；未保存退出确认可取消并保留输入 |
| 并发冲突 | 打开版本1后在隔离库通过真实HTTP更新为7.75000000、版本2；旧表单提交9.0被拒，输入保留并提示重新读取，当前值未覆盖 |
| 创建回滚及恢复 | 版本审计写入触发器延时后报错，当前表及历史均0条；页面保留日期、金额和创建标识。移除故障后同一表单重试，只生成1条当前及1条版本0 |
| 保存过程 | 延时故障期间确认日期、汇率、保存及取消均禁用，关闭入口隐藏；首轮发现日期控件覆盖表单禁用，修正为saving或已有ID后实测通过 |
| 列表读取失败 | 暂时重命名本次当前表，搜索明确显示读取错误，不伪装空列表；恢复表名再次搜索成功 |
| 历史读取失败 | 暂时重命名本次版本表，只读详情仍保留当前值，历史显示错误与重试；恢复表名后重试返回3版历史 |
| 只读范围 | 实际只读账号无新增/编辑按钮，可读详情、3版历史及预览；100 USD按7.75000000得到775.00 CNY、版本2。后端写入越权由HTTP测试拒绝 |
| 筛选与分页 | 13条额外分页夹具，共15条；默认首页10条、次页5条；精确10-11范围筛选1条，重置恢复15条，操作及只读翻页均成功 |

最终数据库核对：15条当前汇率、17条版本；主样例依次7.50000000/7.25000000/7.75000000，版本0/1/2；故障后重试样例7.12345678仅1条/1版。通用操作审计请求/响应正文数0，遗留触发器0，故障表名0。预览不生成修订或业务流水。
