## 实际验证

| 场景 | 结果 |
|---|---|
| 空态与新增必填 | 初始暂无数据；空名称保存出现必填提示，填写合成联系人和结算说明后新增成功 |
| 真实编辑 | 已保存资料完整回填，填写修改原因保存，详情回显修改后备注和对应审计 |
| 启停原因/取消 | 空原因阻止提交；取消停用后状态仍0，数据库STATUS审计仍0 |
| 停用/恢复 | 停用后仍能查看详情和历史，行内入口变“启用”；恢复启用成功，审计分别保留原因和操作人 |
| 保存处理中 | 临时审计触发器延迟并报错；期间名称等输入、保存、取消均disabled，关闭入口隐藏 |
| 失败恢复 | 审计故障导致新增失败，表单保持输入及原创建标识；移除故障后原表单重试成功，数据库按主键核对仅1条供应商、1条创建审计 |
| 并发冲突 | 打开编辑后由实际API先更新；旧版本页面保存被拒并保留输入，数据库未被旧内容覆盖；提示关闭并重新打开核对，不自动升级版本 |
| 名称筛选/重置 | 精确测试片段仅返回目标1条；重置恢复完整列表 |
| 实际翻页 | 通过真实API新增15条ASCII分页样例；筛选后第一页10条、第二页5条，页号2且下一页禁用，记录分段正确 |
| 真实只读账号 | 写按钮计数：新增0、编辑0、停用0、启用0，详情可打开并显示6条来源操作记录；直接写接口403由集成测试核对 |
| 构建与布局 | 最终生产构建退出0；截图核对表单、冲突提示、列表及详情，无控件重叠；窄于表格总列宽时沿用Element Plus横向滚动与右侧固定操作列 |
