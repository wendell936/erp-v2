# Amazon ERP 业务需求清单

更新日期：2026-10-10。

本文作为重新开发的业务需求基线，集中描述业务目标、使用范围、功能和业务规则。各项需求不沿用旧系统的完成状态。

## 1. 业务目标与范围

系统需要帮助运营人员回答：卖什么、缺什么、采购和物流进展如何、何时能补货、每笔销售是否赚钱，以及未来资金是否充足。

- 当前服务一个 Amazon 店铺，仅经营 FBA。
- 配件向不同供应商采购，在国内完成组装、贴标、打包和装箱，以成品套装发往 FBA。
- 支持普通商品、配件和实体套装的管理。
- 面向小团队，同一人员可以完成多个业务环节；提需提交即可执行，采购确认即可下单，无需复杂审核。
- 从新业务数据开始使用，不要求整理历史数据或录入历史期初库存、成本。
- 日常业务自动带入当前店铺，保留未来扩展业务范围的余地。

主流程：商品与套装定义 → 运营提需 → 按供应商采购 → 国内分票运输 → 分批质检收货 → 齐套与加工 → 成品入库 → FBA 发货与接收 → 销售与退货 → 成本利润 → 收付款与现金预测。

## 2. 商品与套装管理

| 编号 | 业务需求 |
|---|---|
| 商品-01 | 建立标准商品档案，维护 SKU、名称、类型、单位、状态、采购价及币种、供应商链接、参考链接（支持多个）、建议售卖定价（美元 USD）、供应商货号和采购交期。新 SKU 按统一编码规则创建，避免重复和一物多码。 |
| 商品-02 | 区分内部 SKU、店铺 MSKU、ASIN、FNSKU 和供应商货号；同一内部 SKU 可以对应多个 MSKU，套装的 MSKU 对应成品套装而不是其中某个配件。 |
| 商品-03 | 维护实体套装的组件清单和每套用量，查看配件图片、单位及供应商；禁止套装包含自身或形成循环组合。 |
| 商品-04 | 保留套装配方版本；采购、加工及销售使用当时确认的版本，后续改配方不改变已发生业务。不可互换的规格或销售内容应建立不同 SKU。 |
| 商品-05 | 维护主图、配件图、包装图，以及按需使用的尺寸图和标签图；支持上传、预览、排序、替换、用途维护、停用和设主图。组合图片应与实际配件数量一致。 |
| 商品-06 | 图片更新后，仍可查看已发生单据引用的原图片；提示缺图、图片与配方不一致等问题。 |
| 商品-07 | 分别维护商品本体、销售包装和出货箱的尺寸重量；记录单位、来源和确认时间。平台规格与实测规格有差异时供人工核对，不直接覆盖已确认值。 |
| 商品-08 | 支持首次 Listing 配对及后续纠错，查看已配对、未配对和资料不完整商品；修改配对前查看受影响业务，保留修改原因和处理结果。 |

具体编码词典根据首组实际商品完善，不把示例编码当作固定规则。

## 3. 供应商与运营提需

| 编号 | 业务需求 |
|---|---|
| 供应-01 | 维护供应商、联系方式、供应商品、报价及币种、交期、结算账期和订金尾款安排。 |
| 提需-01 | 运营按销售商品或套装提出需要多少货、何时需要，记录提出时间、需求数量和目标日期，查看需求负责人、来源和执行进展。 |
| 提需-02 | 按确认的套装配方展开组件需求，根据现有可用配件及其库存分配计算缺口和净采购需求，并按供应商拆分采购单。 |
| 提需-03 | 拆单前查看组件数量、库存分配和采购结果；需求可追踪到采购、运输、收货、加工及 FBA 发货。 |
| 提需-04 | 共享组件按实际分配管理，不向多个需求重复承诺；同一需求不重复生成采购。 |
| 提需-05 | 支持需求变更和取消，显示已执行部分及受影响单据，保留处理记录。 |

## 4. 采购与国内物流

| 编号 | 业务需求 |
|---|---|
| 采购-01 | 创建采购单，维护供应商、商品、数量、单价、币种、交期及付款安排；支持草稿、确认下单、部分收货和完成。 |
| 采购-02 | 采购下单与付款状态分开管理，支持订金、尾款和部分付款；已收货采购不能因再次确认而丢失收货进度。 |
| 采购-03 | 同一采购单支持多次发货和分批收货；保留采购行与需求行的数量关系。 |
| 物流-01 | 国内物流按每票运单独立跟踪，维护承运商、单号、装载商品及数量、发出时间、预计到达、状态和异常。 |
| 物流-02 | 支持人工记录物流轨迹并标明来源；分别查看各供应商、各运单的运输进度。 |
| 物流-03 | 按实际发运和收货计算已发、已收、未收数量，不因仅填写物流单号就增加在途库存。 |
| 收货-01 | 收货关联采购和运单明细，区分签收数量、合格入库、不良和少收；支持分批质检及差异处理，防止超额收货。 |
| 收货-02 | 合格收货形成可追溯库存批次，记录采购来源、数量、实际成本和入库日期。 |
| 运费-01 | 国内运费按每票运单对应配件的实际合格入库件数分摊；不同单位先统一，保留数量基数和分摊结果。 |
| 运费-02 | 少收、不良及相关异常费用单独记录，按实际责任和单据事实处理，不自动混入正常成品成本；无合格入库数量时提示异常。 |
| 运费-03 | 支持先暂估后确认实际费用，以及分批到货、后补运费；分摊合计等于费用总额，不重复计费。 |

## 5. 库存与加工

| 编号 | 业务需求 |
|---|---|
| 库存-01 | 管理仓库、库位、配件库存、成品库存、库存批次及出入库记录；查看可用、已占用和在途数量及来源。 |
| 库存-02 | 正式库存成本采用先进先出（FIFO），每个批次保留实际成本；平均成本仅作查询参考。 |
| 库存-03 | 采购、加工、发货和退货形成连续可追溯的数量与成本记录；库存不能被重复占用或重复扣减。 |
| 加工-01 | 根据套装需求查看齐套量、缺件和可加工量；组件不足时不能当作成品可售。 |
| 加工-02 | 建立加工单，固定配方版本，预约组件并按 FIFO 投料；支持部分完工、损耗及返工记录。 |
| 加工-03 | 完工时扣减实际使用组件并增加成品批次，保留投料批次与产出批次关系，数量和成本可核对。 |
| 加工-04 | 记录贴标、打包、装箱的实际计费单位、数量及单价，以及包材领用；报价已含包材时不重复计费。 |
| 加工-05 | 成品成本由实际组件成本、加工及包材成本组成；损耗和返工费用单列，支持追溯。 |

## 6. FBA 发货、销售与退货

| 编号 | 业务需求 |
|---|---|
| FBA-01 | 管理发货计划、实际发货、头程运输和 Amazon 货件关联，查看商品、箱规、运输渠道、预计到达及进度。 |
| FBA-02 | 分别展示计划、申报、实际发出、Amazon 接收数量及差异；未实际发出的计划不作为实际在途。 |
| FBA-03 | 成品套装发货消费成品库存，保留采购、加工和头程来源，头程按实际箱规及计费依据归集成本。 |
| 销售-01 | 获取当前业务范围内的订单及订单明细，关联 MSKU、内部 SKU、收入、平台费用、退款和销售成本。 |
| 销售-02 | 实体套装销售消费成品成本，不再次扣减组件成本；同一订单重复取得时不重复计算或扣减。 |
| 退货-01 | 区分退款事实和实物退货；退款内商品款冲减与佣金返还分别记录。 |
| 退货-02 | 可售实物退货恢复对应原销售成本；不可售退货单独记录损失，避免重复计损。 |
| 对接-01 | 获取 Listing、商品规格、FBA 库存、订单、财务费用和货件信息；查看各类数据的更新时间、结果和异常，失败后可继续处理。 |
| 对接-02 | 首次订单及费用获取限定新业务启用范围，不回溯启用前业务；缺数据或未更新应明确提示。 |

## 7. 补备货与预警

| 编号 | 业务需求 |
|---|---|
| 补货-01 | 结合可售库存、加权日均或月均销量、可售天数，以及实际采购、国内物流、加工和 FBA 在途进度提供补备货建议，支持调整销量窗口、安全库存和各阶段交期；销量权重及可售天数的具体计算口径在实现前确认。 |
| 补货-02 | 分开显示采购未发、国内已发未收、可齐套组件、可用成品、未发 FBA 计划及 FBA 实际在途，避免重复计量。 |
| 补货-03 | 按预计可用日期判断断货风险；晚到的库存不能掩盖此前缺货，同一组件不能同时满足多个套装需求。 |
| 补货-04 | 对新商品和销量不足商品提示数据不足，允许人工提需；建议可下钻来源并转为需求或发货计划。 |
| 预警-01 | 提供缺货、缺件、延误、超储、资料缺失和数据获取异常的站内预警及待办。 |
| 预警-02 | 预警可查看来源、负责人和处理记录；相同问题不重复刷屏，事实恢复后可关闭。 |

## 8. 成本、费用与经营利润

| 编号 | 业务需求 |
|---|---|
| 财务-01 | 手工金额支持人民币 CNY、美元 USD，成本默认人民币；保留来源原币，不把美元金额直接当人民币。 |
| 财务-02 | 手工维护带日期的“1 USD = X CNY”汇率，确认成本或费用时固定当时汇率及人民币金额；后续修改汇率不改旧记录。缺汇率时提示待处理。 |
| 成本-01 | 完整归集采购、国内运费、贴标/打包/装箱、包材、头程、FBA 配送及其他平台费用，逐项查看来源及归属。 |
| 成本-02 | 进入库存成本的费用通过销售成本结转，不能在利润中再次重复扣除。 |
| 成本-03 | 支持暂估转实际、费用补录和成本调整；已售成本与剩余库存分别调整，调整总额守恒。 |
| 成本-04 | 保留实际、暂估、缺失及参考成本标识；缺资料不能用零成本冒充已确认成本。 |
| 费用-01 | 分类记录佣金、FBA 配送、仓储、退款及其他平台费用，统一金额方向，保留原始明细，防止负费用被算成额外收入。 |
| 费用-02 | 建立经营费用台账，维护租金、工资、广告及其他费用的发生日期、期间、币种、金额、凭证和归属。费用发生与实际付款分开。 |
| 费用-03 | 同一费用在广告报表、平台账单或付款账单中出现时只确认一次；无法分配至订单的费用仍进入公司汇总。 |
| 利润-01 | 查看订单、SKU、MSKU 及公司经营利润；同 SKU 对应多个 MSKU 时分别归属，汇总不能重复扣成本。 |
| 利润-02 | 人民币汇总收入、退款、商品成本、平台费用、广告和期间经营费用；公司经营利润扣除租金、工资等实际期间费用。 |
| 利润-03 | 区分按订单日期和按财务入账/结算日期的报表，解释跨期差异；已关闭期间通过调整记录处理。 |
| 利润-04 | 展示费用是否到齐、成本是否暂估和资料缺口，支持明细下钻；数据不完整时不显示为已确认净利润。 |
| 利润-05 | 先提供直接订单/SKU 利润及公司经营利润；若需要 SKU 全成本利润，再明确间接费用分摊规则并标识分摊部分。 |

## 9. 广告业务

| 编号 | 业务需求 |
|---|---|
| 广告-01 | 先支持新广告报表导入，查看导入前预览、错误项和重复记录，并将广告消耗纳入经营利润。 |
| 广告-02 | 后续自动取得广告账户报表，保留报告日期、时区、归因窗口和修订版本，更新后不重复计算花费。 |
| 广告-03 | 查看活动、关键词、搜索词的花费、点击、转化和归因销售，分析 ACOS、ROAS、TACOS，并说明指标口径。 |
| 广告-04 | 提示高花费低产出、低库存等问题，建议能够回查原数据；缺少报表不能显示为零花费。 |
| 广告-05 | 广告归因销售仅用于分析，不再次增加经营总收入；广告费用与平台扣款、支付记录避免重复。 |

广告账户授权与店铺其他业务授权分开处理。自动修改预算、竞价和投放另行规划。

## 10. 收付款与现金流

| 编号 | 业务需求 |
|---|---|
| 现金-01 | 维护资金账户及启用时实际可用余额，记录收付款、退款和账户间转账。 |
| 现金-02 | 管理采购、加工、物流和其他费用的应付款，支持订金、尾款、部分付款及核销，查看未付金额和到期日。 |
| 现金-03 | 跟踪 Amazon 结算、待到账及实际到账，对账手续费、汇兑差额和退款；待释放资金与可用现金分开。 |
| 现金-04 | 同一费用只确认一次、同一支付只入账一次，账户间转账不作为经营收入或费用。 |
| 现金-05 | 根据实际余额、未收未付及付款计划生成未来 13 周现金预测，提供基础和保守情景。 |
| 现金-06 | 展示最低安全余额、预计资金缺口及对应单据；已赚但未到账利润不作为可支配现金，预测仅计未完成收付款部分。 |

## 11. 日常操作与账号管理

- UI 与操作习惯尽可能参考领星：业务分组导航、顶部多页面签、紧凑筛选区、状态页签、列表操作栏、数据表、分组表单、明细和来源单据跳转；具体页面按本项目小团队 FBA 业务范围取舍。
- 后续各模块和细节实现持续参考领星对应页面及实际交互，覆盖有数据时的行内操作、详情、表单校验和办理路径；各阶段交付核对交互一致性及必要差异。
- 商品选择显示名称、SKU、图片和套装内容，日常人员无需记忆内部编号。
- 金额展示币种、汇率和人民币金额；数量显示单位；状态使用可理解的业务名称。
- 切换页面保留必要筛选和录入，离开未保存内容时提示；操作失败保留已填信息，便于继续处理。
- 区分加载中、无记录、获取失败、未更新和资料待补，不能把失败或缺失显示为零。
- 对产生库存、费用或资金后果的操作，提交前清楚展示本次影响；重复操作不能重复产生业务结果。
- 管理员管理账号及权限，操作人员办理业务，只读人员查看数据；关键变更保留人员、时间、原因和结果。
- 连续五次真实密码失败锁定账号；验证码错误不计入密码失败次数；成功登录清零，到期恢复，管理员可解除临时锁定，停用账号不能因此自动启用。
- 锁定时长可配置，15 分钟为建议初值。

## 12. 业务推进重点

| 顺序 | 业务成果 |
|---|---|
| 首个闭环 | 一套实体商品从商品/图片/配方、提需、两供应商采购、两票物流、分批收货、加工到 FBA 销售，完整追踪数量与成本。 |
| 补备货 | 结合可售库存、加权日均或月均销量、可售天数、实际采购、物流和加工进度判断缺货、齐套与到达时间，形成可办理的预警待办。 |
| 经营利润 | 补齐实际成本、物流费用、平台费用、广告、租金工资及期间口径，判断商品和公司是否赚钱。 |
| 现金管理 | 贯通采购付款、费用支付和平台回款，识别未来 13 周资金缺口。 |
| 广告深化 | 在基础广告费用可用后，完善自动报表及活动、关键词和搜索词分析。 |

## 13. 使用前需补充的业务资料

- 一个真实新套装的商品、配件用量、图片、单位、规格及供应商资料，用于完善编码词典和实际业务样例。
- 贴标、打包、装箱的实际单位和单价，包材是否已包含在报价中。
- 国内物流及头程渠道、实际交期、计费依据、供应商账期和订金尾款比例。
- 正式使用的汇率、费用科目、销量窗口、日均或月均销量的权重、可售天数计算口径、安全库存和预警阈值。
- 当前店铺的数据获取授权与实际可取得的数据范围；广告账户授权或可用新报表。
- 资金账户实际可用余额、收付款周期、租金工资支付安排及最低安全余额。
- 若需要 SKU 间接费用分摊，再补充分摊依据；公司经营利润不依赖此项先行开展。

资料按业务开展环节补充，没有已发生单据时不要求补造历史业务。

## 14. 当前范围之外
