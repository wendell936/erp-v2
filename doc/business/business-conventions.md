# 业务术语、编码与单据规范

## 术语

| 术语 | 统一含义 |
|---|---|
| 内部 SKU | 公司内部商品身份，不等同于 MSKU、ASIN、FNSKU 或供应商货号 |
| 配件 | 采购、入库并用于加工投料的商品角色 |
| 实体套装 | 按固定配方版本加工形成独立成品库存的销售商品 |
| 批次 | 有明确来源、数量和成本的库存追踪单位 |
| 实物库存 | 已实际入库且尚未出库的数量，包含已占用部分 |
| 已占用库存 | 已分配给业务需求、不能再向其他需求承诺的库存 |
| 可用库存 | 满足可用条件的实物库存减去有效占用，不包含在途或未质检合格数量 |
| 在途 | 已实际发运、尚未按相应环节接收的数量；国内和 FBA 分开展示 |
| 销售成本 | 销售实际消费的成品成本，不再次消费其组件成本 |
| 利润与现金 | 利润按收入费用口径计算；现金按实际可用余额和收付款计算 |

不同仓库、质量状态及单位的数量不直接混加；跨阶段汇总明确去重关系。退货及成本处理遵循需求基线，不由术语表另行扩展。

## 编码与状态

- 技术主键与业务编码分离；业务编码不可作为可随意修改的关联键。
- SKU 的具体词典由真实首组商品确认，不把测试编码固化为正式规则。
- 2026-10-12 用户确认组件与其他商品使用同一套 SKU 规则，具体格式及确认边界见[需求基线第 2 章](../requirements/requirements-checklist.md#2-商品与套装管理)。2026-10-14进一步确认类型码仅英文字母数字，连字符专用于SKU层级分隔，前后端及数据库一致限制；编号由系统持久分配，不能照搬工作簿按行位置使用 `COUNTIFS` 生成序号的方式；重排或删除记录不改变其他商品的已有编码。数据库以独立技术主键关联，SKU 业务编码保持唯一。
- 2026-10-13确认SKU是全流程身份，原SKU保留，新增变体只追加后缀；原SKU继续保留自己的库存和业务，新变体各自独立，不自动搬移库存。Seller SKU在本项目称MSKU，与内部SKU通过映射关联，字符不要求相同；一个内部SKU仍可对应多个MSKU。
- 编码父子关系、配方组成和平台映射是不同关系：组件可以跨编码前缀、跨组合复用，不由“同一父级下的所有变体”自动生成配方。组合Seller SKU关联独立成品SKU并展开版本配方，现有实体加工/FIFO及成品消费规则继续有效；展开组件不重复扣组件成本。
- 单据号由服务端生成，数据库唯一约束兜底，不用“查询最大值加一”分配编号。编号不要求无断号，不复用已作废编号。
- 持久化状态使用稳定编码和对应枚举或字典，界面显示业务名称，不散落魔法数字或以显示文字驱动业务。
- 商品单位、费用计费单位、币种使用统一字典或既有标准字段。换算需有明确基数和精度。

## 单据生命周期与纠错

| 阶段 | 操作边界 |
|---|---|
| 草稿 | 可修改和删除，前提是尚无下游引用或业务影响 |
| 已确认 | 固定已确认的关键字段及快照；未执行部分的变更须评估下游影响并留痕 |
| 部分执行 | 按实际执行数量保留进度，只对剩余可执行部分办理后续操作 |
| 已完成 | 不直接改写已发生的数量、金额、来源和成本事实 |
| 取消或纠错 | 未执行部分可按规则取消；已执行部分用关联的退回、冲销或调整记录处理 |

- 上表是设计边界，不强制所有业务共用一个状态枚举。采购、收货、加工、发货分别定义合法转换和前置条件。
- 每类单据开发前明确字段可修改矩阵、允许操作、数量上限、下游依赖及纠错入口。采购状态、付款状态、物流状态分开管理。
- 确认、执行、取消须在服务端重新检查当前状态，通过事务及条件更新或锁控制并发；操作结果与业务流水保持一致。
- 已发生库存、费用或资金影响的记录不得直接物理删除，不以修改库存余额或原金额代替纠错。
- 具体冲销顺序、跨期处理及费用责任不明确时按需求流程确认，不自动推断。

- 用户确认一个 SKU 允许多个供应商报价，并可指定默认供应商；不将工作簿中的单供应商列解释为一对一限制。

## 参考报价、包装与正式成本（2026-10-13）

- 供应-02中的“采购成本”按本轮沟通记录为商品采购报价：非组合配件按单套报价，组合按所选组件用量和报价合计。报价须关联供应商、原币和计价单位，不能直接当成库存FIFO实际成本；实际采购、收货及加工按其来源单据形成成本。
- 变体默认包装字段表示最终销售包装，参考头程计算使用cm和kg；商品本体、销售包装及实际出货箱规仍分别保留。实重是否含销售包装、组合包装值的归属和更新行为待确认，不能自动相加组件尺寸或由平台值覆盖实测。
- 空海运分别使用5000/6000除数，计费重量取实重与相应体积重较大者。CNY/kg是国内原始报价，USD是参考头程结果、尾程报价及销售指导价的币种；具体公式见需求基线测算-01～05。
- “参考”与实际/暂估/缺失分开标识。参考物流测算取不晚于测算日期的最近已维护汇率，显示实际日期；已确认单据继续按明确日期精确取值并固定快照。后续改商品报价、包装、运价和汇率不直接回写已确认库存成本或销售利润。
